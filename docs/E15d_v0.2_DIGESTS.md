## E15d(a) compiler-invariance (20-cell matrix)

`TARGET_DIGEST` retargeted from v0.1's `ba88708b...` to v0.2's
`a0c563ef...`; `TARGET_INVFREQ_DIGEST` unchanged (`da9f6dcfde...`).
First dispatch (run 33195027040) failed on the `inv_freq_table_digest`
comparison only — root cause: a pre-existing CI script bug
(`.github/workflows/e15d-compiler-invariance.yml` grepped the literal
`'^inv_freq table_digest='` with a space; the reference actually prints
`inv_freq_table_digest=` as one token), not a real digest mismatch —
`CIS2_REF` itself matched `a0c563ef...` in all 20/20 cells on that run.
Fixed the grep (commit `bd20ebf`) and redispatched (run 33195649908,
result: PASS, 20/20 jobs matched CIS2_REF=a0c563ef... and
inv_freq_table_digest=da9f6dcfde..., 0 mismatches, 0 FMA instructions in every
cell).
