# Code of conduct

## The standard

Be straightforward and be accurate. That is most of it.

Specifically, in issues, pull requests, reviews and commit messages:

- **Argue about the artifact, not the person.** "This clause is ambiguous
  because X and Y both satisfy it" is the shape of every useful disagreement
  here. Comments about a contributor's competence, motives or identity are
  not.
- **Being right is not a licence to be unpleasant.** Finding a real defect in
  someone's work — including a maintainer's — is a service to the project and
  should be delivered as one.
- **Being wrong in public is fine.** This repository has a changelog full of
  its own corrected errors, and a README section that asks outsiders to try to
  break its central claim. Nobody is penalised for a mismatch, a retracted
  claim, or a question that turns out to have an obvious answer.
- **Do not overstate.** Claiming more than your evidence supports is treated
  as a conduct problem and not only a technical one, because the entire value
  of this project rests on its claims being checkable and checked.

Harassment, discriminatory language, sexualised content, deliberate
intimidation, sustained disruption, and publishing others' private
information without permission are not acceptable in any project space, and
neither is retaliation against someone who reports a problem. This applies to
issues, pull requests, discussions, commits, and any other space where
someone is representing the project.

## Scope

All project spaces on GitHub, and any space where a person is acting as a
representative of this project.

## Reporting

Report a concern privately through GitHub's **Security → Report a
vulnerability** form on <https://github.com/Aefinity-AI/cis2-spec>, which
opens a channel visible only to the maintainers. It is the wrong-shaped form
for the purpose, but it is the only private channel this repository has;
write "conduct" at the top and it will be handled as such, not as a security
report.

Reports are read by the maintainers. You will get an acknowledgement within
7 days. Retaliation against a reporter is itself a violation.

## Enforcement

Maintainers may, in proportion to the conduct: ask for a correction, edit or
remove a comment, close an issue or PR, or block an account from the
repository. Where the person acted in good faith and is willing to correct
it, the first step is a private request to do so.

Maintainers who violate this document are subject to it on the same terms.
