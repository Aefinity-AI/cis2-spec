# ev-1 mini eval kit — item sources and licenses

Total items: 160 (≤ 200 cap), across 4 categories.

| Category | Items | Source | License |
|---|---|---|---|
| `truthfulness` | 60 | Stratified sample of `TruthfulQA.csv` from `sylinrl/TruthfulQA` (https://github.com/sylinrl/TruthfulQA), commit as of 2026-09-22, fetched via `raw.githubusercontent.com`. Stratified round-robin across all 38 TruthfulQA `Category` values so no single topic (e.g. "Misconceptions") dominates the sample; deterministic seed 20260922. | Apache License 2.0 (see `LICENSE` at the same repo; verified by fetching it directly before use). |
| `self_consistency` | 20 | Hand-written by this task (Claudius Maximus / Aefinity AI Inc.), simple factual-continuation prompts (e.g. "The capital of France is", "Two plus two equals"). No external dataset. | Original, CC0 / public domain. |
| `tool_use` | 60 | Hand-written arithmetic-completion items, generated by `eval/make_items.py`'s `build_tool_use()` from a fixed PRNG seed (7) over small integer addition/subtraction. This is a narrow proxy for "tool-use correctness" — see the caveat in `docs/results/2026-09-22-ev1-mini-eval-kit.md` on why a real tool-call-format eval isn't meaningful on this base model. No external dataset. | Original, CC0 / public domain. |
| `refusal` | 20 | Hand-written narrow refusal-behavior probes (10 "should refuse" topic-level requests, 10 matched "should comply" benign requests). Deliberately non-operational / non-actionable — topic-level requests only, no instructions. No external dataset. | Original, CC0 / public domain. |

Regeneration: `eval/make_items.py` (kept for provenance; not re-run automatically
by `eval/run_eval.py`, since committed `eval/items/*.jsonl` is the frozen,
reviewed item set). Re-running `make_items.py` against a fresh
`TruthfulQA.csv` download is expected to reproduce the same 60
`truthfulness` items given the same seed and the same upstream CSV row
order; it is not re-verified against network access as part of `run_eval.py`.
